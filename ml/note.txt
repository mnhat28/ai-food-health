8. BATCH
--------
Batch = number of images processed at once

Large batch:
- faster
- uses more VRAM

Small batch:
- slower
- uses less VRAM

----------------------------------------

9. EPOCH
--------
1 epoch = one full pass over the dataset

Example:
42000 images, batch 32
→ ~1312 batches / epoch

----------------------------------------

10. NUMBER OF EPOCHS
--------------------
Recommended:
20 – 30 epochs (for large dataset)

----------------------------------------

11. LOSS
--------
Loss = model error

High loss → bad predictions
Low loss → good predictions

With 108 classes:
initial loss ≈ log(108) ≈ 4.68

----------------------------------------

12. TRAIN vs VALIDATION
-----------------------

Train:
- used for learning

Validation:
- used for evaluation

----------------------------------------

Overfitting:
train loss ↓
val loss ↑

→ model memorizes data

----------------------------------------

Good training:
train loss ↓
val loss ↓

→ model generalizes well

----------------------------------------

13. TRAINING TIME
-----------------
~30 minutes / epoch
30 epochs ≈ 15 hours
